Dúvidas frequentes do cantinho.

Aqui você encontra respostas gerais sobre patches e arquivos de jogos de PS1. Para aplicar uma tradução, siga sempre as instruções que acompanham o pacote daquele projeto: os formatos e as ferramentas podem variar.

Para consultar quando precisar

Perguntas e respostas

Abra uma pergunta para ver a orientação completa.

01Meu Windows é de 32 bits ou uso outro sistema. Como aplico o patch?+

Os requisitos dependem do aplicador que acompanha cada tradução. Confira as instruções do pacote para saber quais sistemas são compatíveis e se há uma alternativa manual. Patches de formatos diferentes podem exigir ferramentas diferentes.

Para patches .xdelta, uma opção é o Delta Patcher, disponível no projeto oficial para Windows, macOS e Linux. Escolha a versão correspondente ao seu sistema; no Windows de 32 bits, procure o pacote para x86. A aplicação manual com essa ferramenta já foi testada no projeto Legend of Legaia, mas confira as instruções de cada tradução antes de usá-la.

Se o pacote da tradução indicar o Delta Patcher:

  1. Baixe a versão adequada ao seu sistema e extraia o ZIP da tradução.
  2. Faça uma cópia da imagem original do jogo em uma pasta separada. Se usar .BIN e .CUE, copie os dois arquivos.
  3. No Delta Patcher, selecione como arquivo original a cópia do .BIN ou .ISO indicada nas instruções.
  4. Selecione o arquivo .xdelta fornecido com a tradução e aplique o patch mantendo a verificação de integridade ativada.
  5. Se ocorrer erro de incompatibilidade, não desative a verificação para forçar a aplicação: confira a edição e o formato da imagem exigidos pelo projeto.
  6. Abra o jogo traduzido conforme as instruções do pacote. Se houver .BIN e .CUE, mantenha-os juntos e confira a referência dentro do .CUE.

A aplicação manual pode não criar as mesmas pastas ou arquivos adicionais do aplicador fornecido com a tradução. Guarde o guia COMO INSTALAR.txt e as demais instruções do pacote para consultar a versão e os detalhes específicos do projeto. No caso de Legend of Legaia, o aplicador também cria VERSAO DA TRADUCAO.txt na pasta do jogo traduzido.

02O que são BIN e CUE? Como confiro o nome dentro do CUE?+

Em jogos com imagem .BIN e .CUE, o .BIN contém os dados do disco. O .CUE é um pequeno arquivo de texto que descreve as faixas e aponta para os dados; sozinho, ele não contém o jogo.

  1. Abra o .CUE no Bloco de Notas ou em outro editor de texto simples.
  2. Procure uma linha como FILE "Meu Jogo.bin" BINARY.
  3. Confirme que há, na mesma pasta, um arquivo com exatamente o nome indicado entre aspas, incluindo espaços e extensão. Se necessário, ative a exibição das extensões dos arquivos.
  4. Se precisar corrigir a referência, altere somente o nome entre aspas e salve mantendo a extensão .cue, sem acrescentar .txt.

Se houver várias linhas FILE, confira cada arquivo indicado. Você pode consultar também a explicação do formato CUE no manual do GNU ccd2cue.

03BIN e CUE precisam ter o mesmo nome?+

Não. O nome do .CUE pode ser diferente. O importante é que a referência FILE dentro dele aponte para o nome do .BIN correto.

Por exemplo, Traducao.cue pode apontar para Meu Jogo.bin se contiver a linha FILE "Meu Jogo.bin" BINARY. Mantenha os arquivos na mesma pasta e, se renomear o .BIN, atualize essa referência no .CUE.

04Posso aplicar o patch em uma imagem ISO?+

Depende da tradução. Um patch pode ter sido preparado para um .ISO, um .BIN ou outro formato específico. Confira na página do projeto e no guia de instalação do pacote qual imagem original e qual edição do jogo são exigidas.

A extensão, sozinha, não garante compatibilidade. Um patch preparado para uma imagem .BIN não deve ser aplicado a um .ISO diferente. Renomear .iso para .bin não converte o arquivo, e converter entre formatos também não garante que o patch funcione.

05Como relato um erro de tradução?+

Abra a página do jogo na estante de traduções e procure a opção Relatar um erro. Cada projeto terá seu próprio formulário, com as instruções de envio e os tipos de anexo aceitos para aquele jogo.

Para ajudar na correção, descreva o que parece incorreto e onde o problema apareceu. Informe a versão indicada no guia COMO INSTALAR.txt que acompanha o patch. Em Legend of Legaia, quem usou o aplicador também pode consultar VERSAO DA TRADUCAO.txt na pasta do jogo traduzido. Se o formulário permitir, envie também uma captura de tela.

Envie um problema por relato, mesmo que pareça pequeno, como uma palavra em inglês ou um acento incorreto. Antes de enviar, confira na página do jogo as orientações de privacidade e os requisitos do formulário correspondente.
