# Cantinho da Angélica

Traduções brasileiras de jogos de PlayStation feitas por Angélica.

O site reúne informações, andamento, instruções e downloads dos projetos de tradução. A primeira tradução apresentada é **Legend of Legaia para PlayStation**.

## Site

Quando o GitHub Pages estiver ativado, o endereço será:

<https://lunavyren.github.io/cantinho-da-angelica/>

## Estrutura

- `index.html`: página inicial e catálogo de traduções;
- `projetos/legend-of-legaia/`: página do primeiro projeto;
- `assets/`: estilos, comportamento e identidade visual;
- `sitemap.xml` e `robots.txt`: descoberta das páginas por mecanismos de busca.

## Aviso

Este é um projeto independente de fãs. As traduções são distribuídas apenas como patches e exigem que cada pessoa possua o jogo original.
